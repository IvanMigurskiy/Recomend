# Выпускная квалификационная работа бакалавра: Применение алгоритмов машинного обучения для создания модели рекомендательной системы фильмов

Этот репозиторий содержит материалы выпускной квалификационной работы бакалавра на тему "Применение алгоритмов машинного обучения для создания модели рекомендательной системы фильмов".

## Содержание

В рамках работы были реализованы и проанализированы три различные модели рекомендательных систем:

1.  **Вероятностная матричная факторизация (PMF)**: Модель, основанная на разложении матрицы предпочтений на два низкоранговых множителя, с применением вероятностного подхода.
2.  **Байесовская вероятностная матричная факторизация (BPMF)**: Вероятностная модель, расширяющая PMF за счет байесовского подхода и использования методов Монте-Карло с цепью Маркова (MCMC) для вывода.
3.  **Крупномасштабная параллельная коллаборативная фильтрация (ALS)**: Алгоритм, основанный на методе наименьших квадратов с взвешенной λ-регуляризацией, ориентированный на масштабируемость и параллельную обработку.

## Структура репозитория

### Папка `recommend`

*   `base.py`: Абстрактный базовый класс `ModelBase` для всех рекоммендательных моделей. Определяет основные методы, такие как:
    *   `fit(self, train, n_iters)`: Метод для обучения модели на тренировочных данных в течение заданного числа итераций.
    *   `predict(self, data)`: Метод для получения предсказаний на основе обученной модели.
*   `exceptions.py`: Файл с пользовательскими исключениями:
    *   `DimensionError`: Выбрасывается при несоответствии размерностей данных.
    *   `NotFittedError`: Выбрасывается, если попытка сделать предсказание происходит до обучения модели.
*   `als.py`: Реализация алгоритма крупномасштабной параллельной коллаборативной фильтрации (`ALS`), наследующегося от `ModelBase`.
*   `bpmf.py`: Реализация байесовской вероятностной матричной факторизации (`BPMF`), наследующегося от `ModelBase`.
*   `pmf.py`: Реализация вероятностной матричной факторизации (`PMF`), наследующегося от `ModelBase`.

### Папка `recommend/utils`

*   `datasets.py`: Содержит утилиты для работы с данными:
    *   `make_ratings(...)`: Функция для генерации синтетических данных о рейтингах.
    *   `load_movielens_ratings(ratings_file, separator)`: Функция для загрузки данных из файла рейтинга MovieLens.
    *   `build_user_item_matrix(n_users, n_items, ratings)`: Функция для построения матрицы "пользователь-предмет" из списка рейтингов.
*   `evaluation.py`: Утилиты для оценки качества моделей:
    *   `RMSE(estimation, truth)`: Функция для расчета среднеквадратической ошибки (Root Mean Squared Error).
*   `validation.py`: Утилиты для валидации данных:
    *   `check_ratings(ratings, n_user, n_item, max_rating=None, min_rating=None)`: Функция для проверки корректности данных о рейтингах.

## Структура работы (в документе)

Работа состоит из следующих основных разделов:

*   **Введение**: Описание актуальности темы, постановка целей и задач исследования.
*   **Рекомендательные системы**: Обзор существующих подходов к построению рекомендательных систем, их классификация и примеры применения.
*   **Вероятностная матричная факторизация (PMF)**: Теоретическое описание модели, ее реализация на Python и экспериментальные результаты.
*   **Байесовская вероятностная матричная факторизация (BPMF)**: Описание модели, алгоритма MCMC, реализация на Python и результаты экспериментов.
*   **Крупномасштабная параллельная коллаборативная фильтрация (ALS)**: Теория ALS, детали реализации с использованием взвешенной λ-регуляризации, программная реализация и оценка эффективности.
*   **Сравнение моделей рекомендательных систем**: Тестирование всех трех моделей на датасете MovieLens, сравнительный анализ их производительности (RMSE) и выводы.
*   **Заключение**: Итоги проделанной работы, основные выводы и рекомендации по дальнейшему развитию.
*   **Список источников**: Список литературы, использованной при подготовке работы.
*   **Приложение А**: Ссылка на код реализации моделей.



## Цель работы

Алгоритмизация построения систем коллаборативной фильтрации на языке программирования Python с применением эффективных методов и технологий машинного обучения.

## Результаты

В ходе работы были программно реализованы три модели коллаборативной фильтрации (PMF, BPMF, ALS), проведен их сравнительный анализ на датасете MovieLens. Модель ALS продемонстрировала наилучшую производительность по метрике RMSE.
